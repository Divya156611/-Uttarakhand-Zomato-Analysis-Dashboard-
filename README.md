 Uttarakhand Zomato Dashboard
This Power BI dashboard provides an insightful analysis of Zomato restaurants in Uttarakhand, with a focus on Dehradun. It highlights top-rated establishments, cost tiers, delivery availability, and clustering by tourist vs. local preferences.

Features::
Key Metrics: Total restaurants (22 in Uttarakhand), average cost for two (₹690.09), and average rating (4.46).
​
Top 25 Dehradun Restaurants: Visualizes count by rating tiers and cost analysis.
​
Top Dehradun Locals: Breaks down by cuisines like Chinese, North Indian, Mughlai, Fast Food.
​
Cost vs. Rating: Compares tourist and local segments with mid-range focus.
​
Restaurant Clusters: Maps Dehradun areas with delivery options and filters.
​
Dashboard Preview::​

Technologies Used:
Power BI Desktop for visualization and DAX measures.

Interactive elements: Slicers for cost tiers, locality (tourist/local), and delivery.

How to Use :
Download the .pbix file from this repo.

Open in Power BI Desktop (free from Microsoft).

Refresh data if source CSV is provided.

Interact with slicers for dynamic insights.​

Dataset:
Zomato-inspired data for Uttarakhand restaurants, focusing on Dehradun. Includes ratings, costs, cuisines, and location clusters. Source: Custom or Kaggle.
​
Installation:
Power BI Desktop​
No additional setup needed for viewing.

Insights"
Dehradun averages 4.46 rating with mid-range pricing dominant.

Tourist spots cluster differently from locals, aiding location-based decisions.
